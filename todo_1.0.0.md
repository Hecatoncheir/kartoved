- [x] Подключить тёмную палитру Gruvbox на всех экранах. Использовать графит `#282828` для фона, кремовый `#FBF1C7` для текста и янтарный `#FABD2F` для основных действий и рамки сканера.
- [x] Подключить локальные Nunito, Nunito Sans и JetBrains Mono для заголовков, текста, кодов изданий и счётчиков. Добавить файлы лицензий в ресурсы приложения.
