# Прототип интерфейса «Картовед»

Откройте `index.html` в браузере. Шрифт, иллюстрации и демонстрационные данные лежат в репозитории, поэтому достаточно локальных файлов. Изменения в коллекциях сохраняются в хранилище браузера. Сканер работает с демонстрационным кадром, а поиск — с небольшим набором карт.

## Что попробовать

- В «Основной коллекции» найдите Sol Ring, нажмите «Выбрать карты» и затем «Выбрать лишние». Прототип предложит к переносу два обычных и один фольгированный экземпляр. Количество можно изменить до подтверждения.
- Откройте «Сканер», выберите альбом и нажмите «Сканировать пример». Проверьте язык и покрытие, затем подтвердите карту. Если закрыть окно проверки, снимок останется в очереди выбранного альбома.
- В каталоге найдите «Контрзаклинание», выберите издание и количество. Переключатель «Мои карты» покажет альбомы с добавленными экземплярами.

## Для переноса во Flutter

| Элемент | Ориентир |
| --- | --- |
| Цвета | Тёмный Gruvbox. Фон `#282828`, панели `#32302F`, основной текст `#FBF1C7`, акцент сканирования `#FABD2F`. Переменные собраны в начале `styles.css`. |
| Типографика | Nunito для заголовков, Nunito Sans для основного текста, JetBrains Mono для кодов и числовых полей. Файлы находятся в `assets/fonts`, лицензии — в `assets/licenses`. |
| Навигация | Нижняя панель на телефоне с центральным сканером. Боковая панель появляется при ширине больше 760 CSS-пикселей. |
| Альбомы | Горизонтальный список обложек на телефоне, сетка в три столбца на широком экране. Высота основных сенсорных целей — от 44 CSS-пикселей. |
| Варианты карты и проверка кадра | Нижняя модальная панель на телефоне, диалог по центру на широком экране. Издание, номер, язык и покрытие видны в момент выбора. |
| Массовый перенос | Выбор количества хранится отдельно для каждого варианта. Назначение задаётся на всю подборку. Новый альбом создаётся при подтверждении операции. |

Для иллюстраций карточек и трёх обложек использованы изображения Scryfall. Главная обложка `assets/design/hero.webp` сгенерирована по описанию веера коллекционных карт на матовом тёмно-зелёном столе.
